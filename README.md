# Seasonal-distribution-of-Amblyomma-ticks-in-the-Neotropical-region-a-meta-analytical-approach
Projeto desenvolvido durante o doutorado, envolvendo revisão sistemática, construção e organização de bases de dados, análise estatística, meta-análise e avaliação de variáveis ambientais e geográficas. Utilização de R para tratamento, análise e visualização dos dados.
